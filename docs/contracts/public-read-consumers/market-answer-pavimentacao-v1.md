# Market Answer — typical paving-contract value

Question: **Qual é o valor típico dos contratos públicos de pavimentação?**

Grain is `integral_nominal_instrument`. That is not cost/km and not a unit
price. If typology, denominator or coverage fail, the payload is `NEEDS_DATA`.
The grain is never relaxed to serve a URL.

A national geography (`BR`) requires `#302` `national_claim_allowed=true` and
`nacional_completo=true`. Extra 1093 is never a national denominator.

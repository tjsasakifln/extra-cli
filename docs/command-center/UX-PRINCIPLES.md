# UX Principles

1. Answer “what needs my attention now?” above the fold.
2. Technical codes remain visible **with** human translation.
3. Metrics always carry denominators.
4. Distinguish healthy / attention / external block / technical block / human review / partial / proven.
5. ACCEPT is never a casual green primary for sensitive decisions.
6. Keyboard first: focus, skip link, Ctrl+K palette.
7. Light / dark / system themes with design tokens (not inverted screenshots).

# Quickstart — Consulting Workbench

```bash
# From repo root
./bin/command-center
# → http://127.0.0.1:8765
```

## First consulting task (no terminal after launch)

1. Open **Iniciar trabalho**
2. Choose **Encontrar oportunidades para a Extra**
3. Keep “dados de demonstração” on if no weekly pack/DSN
4. Confirm phrase → watch stages → open PDF/XLSX in job results
5. Open **Revisões** → decide with real rationale
